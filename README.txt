SEEDTROID SOURCE PATCHES v8v

This archive contains only the code entries changed by Seedtroid.
It does not include AM2R, Multitroid, executables, data.win, music, sprites, or other game assets.

CONTENTS

patches\CodeEntries\
    The 71 modified GML code entries.

server_patches\CodeEntries\
    The modified Multitroid Server GML code entries.

PATCH_MANIFEST.txt
    Full list of included code entries.

WHAT THIS IS FOR

- Publishing the source changes on GitHub.
- Reviewing how Seedtroid changes Multitroid.
- Keeping a backup of the mod's code modifications.

WHAT THIS IS NOT

This is not an installable AM2R mod by itself.
To play Seedtroid, use the Atomic package created from the complete modified game folder, or use the supplied data.win release.

GITHUB

Extract this ZIP, then upload the contents of this folder to a new GitHub repository.
Do not upload AM2R.exe, data.win, original game assets, or profile.xml.

SERVER SOURCE

The server changes are included separately under server_patches.
They were extracted from the supplied server data.win without changing that file.
