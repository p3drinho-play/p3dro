# Seedtroid

Seedtroid is a procedural survival-style expansion for AM2R Multitroid.
Every run generates a new world with large rooms, combat encounters, shops, score progression, relics, environmental hazards, and boss rooms.

## Features

- Procedural world generation with large rooms and random platforms.
- Score, combo counter, and score multiplier.
- Golden elite enemies with increased health and higher score rewards.
- Metroid encounters, flawless Metroid rewards, and special enemy rooms.
- Boss encounters every 45 rooms.
- Federation shops every 25 rooms.
- Shops sell Missile expansions, Super Missiles, Energy Tanks, Power Bombs, and modifiers.
- Permanent run relics with effects such as speed, energy, missile capacity, item chance, Metroid chance, and regeneration.
- Environmental lava rooms with no lockdown.
- Lockdowns require every enemy in the room to be defeated.
- The run ends at room 1000 with a final Queen encounter.
- Death respawns the player in the first room of the same generated world.
- F8 is disabled.

## Installation

1. Make a backup of your current `data.win`.
2. Rename the Seedtroid file to `data.win`.
3. Place it in your AM2R Multitroid game folder.
4. Launch the game and open a save file.

## AM2RLauncher Installation

Use Atomic to build an AM2RLauncher-compatible package.

1. Create a ZIP from the contents of a complete modified AM2R Multitroid folder.
2. Do not include `profile.xml`.
3. The ZIP must contain the files directly at its root, not inside an extra folder.
4. In Atomic, enable Windows support and load that ZIP.
5. Load your AM2R 1.1 ZIP, then create the mod package.

## Notes

- This mod does not include AM2R itself.
- Keep backups of your save files before testing new versions.
- Multiplayer compatibility requires players to use matching client and server builds.
